## 本轮实际修复

1. 注册机构选项只显示国家，同一国家的多个机构无法区分：桌面和移动端增加机构名称/代码。
2. 桌面金额输入框 min=0.01、step 默认 1，合法整数金额被浏览器原生校验拦截：改为 0.01 步长。
3. 改价复用上一笔幂等键，返回成功但金额没变：新提交独立键，相同未确认请求才复用，成功后清空。
4. 首次认证/加入企业后仍持无机构令牌，WS 拒绝：取得机构后重新签发明确机构的令牌，不跳转当前页面。
5. WS 首连失败没有轮询、排名错误依赖精确名次：连接使用配置地址；连接失败启动真实 API 轮询；按 hasQuote、领先/区间/精确模式展示；提交后刷新排名。
6. 报价与评审页面使用客户端时区：桌面/移动报价、评审页使用招标机构时区并标明时区。
7. 异步启用线路金额框后 Element Plus 内部 aria-disabled 残留 true：同步无障碍状态；线路必填字段未填时明确阻止提交并提示，桌面/移动一致。
8. 评审页面硬编码中文且按钮不遵循角色：接入现有五语言资源、格式化与能力控制，覆盖评标员冻结快照。
9. 旧线路历史按当前轮次查询导致空结果：改为按线路所属轮次读取；旧轮或失效线路禁止新报价，避免跨轮污染。

按项目 ui-ux-pro-max 工作流检查了多机构选项可辨识性、字段错误反馈、禁用状态与手机布局；保留既有 Vue / Element Plus 交互风格。
